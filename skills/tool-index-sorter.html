🧪 데모 데이터가 자동으로 올라가 있습니다. 실제 참가자 정보가 아닌 무작위 생성 가상 데이터입니다. CP1에서 원본 기록이 코스별로 정리되는 과정을, CP2에서 변경 요청이 배번 기준으로 자동 매칭되는 과정을 그대로 체험해보실 수 있습니다. (CP2에서는 매칭 실행 버튼을 눌러보세요.)

원본 기록 파일을 코스별로 정리합니다

계측 업체가 준 원본 파일(코스별 시트, 등수·완주시간·성별·배번 등 포함)을 올리면, 영문 성/이름이 없는 참가자를 제외하고 생년월일 형식을 맞춰 코스별 시트로 다시 만들어드립니다.

코스원본 인원정리 인원제외형식 확인

⚠ 검토가 필요한 인원 (형식/내용 확인 필요)

아래 값을 직접 수정할 수 있습니다. 문제없다고 판단되면 그냥 두셔도 되고, 이 사람을 최종본에서 빼려면 체크박스를 해제하세요.

영문 이름이 없어서 제외된 인원

영문 성/이름을 직접 입력하고 "포함하기"를 체크하면 최종본에 포함됩니다.

변경 요청을 매칭하고, 확인 후 반영합니다

배번(Bib Number)을 기준으로 매칭합니다. 팀(2인 1조) 신청처럼 한 줄에 두 명이 같이 들어온 응답은 자동으로 분리해서 각각 매칭합니다.

🆕 신규 추가 후보 (이 명단에 없는 사람)

응답서에는 있지만 현재 명단에는 없는 배번입니다. 새로 등록하는 참가자로 보입니다. 값을 확인/수정하고, 추가하려면 체크박스를 켜두세요. 적용 시 완주시간 기준으로 전체 순위를 다시 계산합니다.

ℹ️ 다른 코스 응답 — 이 파일 범위 아님

아래는 이 마스터 파일에 없는 코스(또는 종목)의 응답입니다. 해당 코스 파일에서 처리해주세요. 여기서는 반영되지 않습니다.
